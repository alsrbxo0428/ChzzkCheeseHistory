# 개인정보 처리방침 (Privacy Policy)

최종 업데이트: 2026-05-14

Chzzk Cheese History(이하 "확장 프로그램")는 사용자의 개인정보를 중요하게 생각합니다.

## 1. 데이터 수집

본 확장 프로그램은 개인정보를 수집, 저장, 판매, 공유하거나 외부 서버로 전송하지 않습니다.

모든 데이터 처리는 사용자의 브라우저 내부에서만 수행됩니다.

## 2. 권한 사용 목적

본 확장 프로그램은 아래 사이트에서만 동작합니다.

* https://chzzk.naver.com/
* https://game.naver.com/

확장 프로그램은 다음 정보를 조회하고 시각화하기 위해 사이트 접근 권한을 사용합니다.

* 치즈 후원 내역
* 구독 선물 내역
* 통계 시각화 데이터

## 3. 데이터 저장

본 확장 프로그램은 사용자의 개인정보를 외부에 저장하지 않습니다.

또한 사용자 데이터를 제3자에게 전송하지 않습니다.

## 4. 제3자 서비스

본 확장 프로그램은 다음 항목을 사용하지 않습니다.

* 광고 서비스
* 사용자 추적 서비스
* 원격 코드 실행
* 외부 분석 시스템

## 5. 정책 변경

확장 프로그램 기능 변경 시 본 개인정보 처리방침이 수정될 수 있습니다.

# Privacy Policy

Last Updated: 2026-05-15

Chzzk Cheese History ("the extension") respects users' privacy.

## 1. Data Collection

This extension does not collect, store, transmit, sell, or share personal information with external servers.

All data processing is performed locally within the user's browser.

## 2. Permissions Usage

The extension operates only on the following websites:

* https://chzzk.naver.com/
* https://game.naver.com/

The extension uses this access to retrieve and display:

* Cheese donation history
* Gift subscription history
* Statistical visualization data

## 3. Data Storage

The extension does not permanently store personal data outside the user's browser.

No user data is transmitted to third parties.

## 4. Third-Party Services

This extension does not use:

* Advertising services
* Analytics services
* Remote code execution
* External tracking systems

## 5. Changes to This Policy

This privacy policy may be updated in the future if the extension functionality changes.
